# Inventory Management Reinforcement Learning Project

This repository contains a shared Gymnasium environment for the Warehouse Inventory Management problem and placeholder training scripts for three RL algorithms:
- Tabular Q‑Learning
- Deep Q‑Network (DQN)
- Proximal Policy Optimization (PPO)

The environment, configuration, and evaluation utilities are shared across all algorithms. Each team member works only on their respective `train_*.py` file.
